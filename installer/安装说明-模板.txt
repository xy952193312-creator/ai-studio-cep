AI Studio · Photoshop 面板  安装说明
================================================================

一、安装（三步）
----------------------------------------------------------------
1. 双击 AIStudio-CEP-Setup-__VERSION__.exe

2. 如果弹出「Windows 已保护你的电脑」
   → 点「更多信息」→「仍要运行」
   （原因见第二节，不是程序坏了）

3. 装完后请**完全退出 Photoshop 再重新打开**
   新装的扩展不会热加载，这一步不能省。

然后在 Photoshop 里打开：窗口 → 扩展功能 → AI Studio
首次使用需要到面板「我的」页填一次 API Key。
安装程序不收集、也不预置任何密钥。


二、为什么会有「Windows 已保护你的电脑」
----------------------------------------------------------------
这个文件没有代码签名证书（一张证书年费几百到几千元）。
这不是程序有问题，而是"未签名"这件事本身的代价。

签名的作用是向 Windows 证明"这个文件是谁发的、发出后没被改过"。
没签名，Windows 就只能通过"这个文件下载量够不够多"来判断，
新文件必然被拦。你可以用第三节的办法自己确认文件没被动过。


三、核对文件没被改过（可选）
----------------------------------------------------------------
在文件所在目录打开 PowerShell，执行：

    certutil -hashfile AIStudio-CEP-Setup-__VERSION__.exe SHA256

和下面这个值完全一致，就说明文件是原封不动的：

    __SHA256__


四、让 Windows 不再拦（可选，做一次就行）
----------------------------------------------------------------
从网上下载的文件会被打上"来自互联网"的标记，Windows 因此多拦一层。
去掉这个标记：

    右键 exe → 属性 → 底部「安全」区域 → 勾选「解除锁定」→ 确定

之后双击就不会再出现那个拦截窗口了。
（注意：去掉的只是"来源不明"的警告，程序本身依然没有签名。）


五、卸载
----------------------------------------------------------------
Windows 设置 → 应用 → 已安装的应用 → 找 AI Studio → 卸载
（或：控制面板 → 程序和功能）

卸载**只删程序文件**。这些内容都会保留，需要的话请自行处理：
  · 生成的图片和对话（在面板「我的 → 存储位置」能看到路径）
  · API Key 与模型配置（面板「我的」页可一键清除）


六、它会改动哪些系统设置
----------------------------------------------------------------
只改一处，而且只影响你自己的 Windows 账户：

    HKCU\Software\Adobe\CSXS.9 ~ CSXS.20 的 PlayerDebugMode = 1

这是 Adobe 官方留给开发者的开关，含义是"允许加载未经签名的扩展"。
本面板没有购买 Adobe 的签名证书，所以必须打开它才会被加载。

两点要清楚：
  1. 它对本机**所有**未签名扩展生效，不只是本面板；
  2. 安装向导里有一页专门讲这件事，复选框默认勾着，但可以取消 ——
     不勾选的话文件照常安装，只是 Photoshop 不会加载它。

不需要管理员权限，不会弹 UAC，不写 Program Files，
一切都在你自己的用户目录和 HKCU 里。


七、出问题先查这里
----------------------------------------------------------------
· 「扩展功能」里找不到 AI Studio
  多半是没重启 Photoshop。完全退出再开一次。
  还不行的话，检查安装时是否勾选了"开启未签名扩展加载"。

· 面板打开了但出图失败
  到「我的」页确认 API 地址和 Key 填对了。安装程序不预置任何地址。

· 想看安装过程到底做了什么
  在命令行里跑：AIStudio-CEP-Setup-__VERSION__.exe /LOG=C:\install.log
  日志里会写清楚检测到几个 Photoshop、有没有写注册表。
